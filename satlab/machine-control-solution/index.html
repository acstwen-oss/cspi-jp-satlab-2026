Series Overview

施工機械に合わせて選べる、3つのMachine Controlソリューション。

掘削、押土、整地という異なる作業に合わせ、現場で必要なガイダンスと自動制御を提供します。各製品の特徴と最新版カタログをこのページから確認できます。

油圧ショベル / Excavator

E10 / E20 / E50 Guidance System

油圧ショベルのバケット位置、深さ、勾配をリアルタイムに表示し、設計面に沿った掘削を支援するマシンガイダンスシリーズです。

3モデル展開

  • Lightdig 3D E10
  • Flexidig 3D Compact E20
  • Flexidig 3D E50

施工の見える化

目視測定と手戻りを減らし、画面上で掘削深さと設計面との差を確認できます。

2D / 3D対応

E10は2D表示、E20とE50は2D/3D表示に対応。現場規模と作業内容に合わせて選択できます。

現場記録

E50は設計ファイルのインポートと作業軌跡の記録に対応し、より高度な施工管理を支援します。

ブルドーザー / Bulldozer

D60 / D60Pro 3D Control

ブルドーザーのブレードを設計面に合わせて制御し、押土、造成、粗整地の施工効率と仕上がり精度を高めます。

D60 Standard

  • マスト付き構成
  • 作業効率56%向上
  • 標高精度 ±3cm

D60Pro

  • マストレス構成
  • 作業効率63%向上
  • 死角と衝突リスクを低減

高精度制御

GNSS、IMU、油圧バルブを連携し、設計面に沿ったブレード高さ制御を支援します。

簡単な運用

タブレット上で施工状況を確認し、丁張り作業や再施工を減らします。

モーターグレーダー / Motor Grader

G60 Grader 3D Control

モーターグレーダーの長いブレードを高精度に制御し、道路路盤、勾配形成、広い施工面の仕上げ整地を支援します。

Fine Grading

連続する施工面の高さと勾配を管理し、均一で滑らかな仕上がりを実現します。

3D設計面

設計データとブレード位置を連携し、オペレーターの判断と作業を支援します。

道路施工

路盤整形、勾配形成、仕上げ整地など、広い面の高精度施工に適しています。

システム構成

AT400アンテナ、TD122タブレット、MC101、TS121 IMU、HV122油圧制御弁で構成。
