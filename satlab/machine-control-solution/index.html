D60 Bulldozer 3D Control

推土機 / Bulldozer

D60はブルドーザー向けの3Dマシンコントロールです。土工、粗整地、造成工事など、ブレードで土を押しながら面を作る施工に適しています。

Standard Version / マスト付き

  • 作業効率 56% 向上
  • 多くの施工シーンに対応
  • 標高精度 ±3cm
  • アンテナ溶接式、ベースを常設

Pro Version / マストレス

  • 作業効率 63% 向上
  • 衝突リスクが低く、死角を完全排除
  • 整地精度が安定し、仕上がりが滑らか
  • アンテナ磁気吸着式、簡単着脱

G60 Motor Grader 3D Control

Fine Grading

System Configuration
